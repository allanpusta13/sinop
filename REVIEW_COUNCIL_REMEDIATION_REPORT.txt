## 2. §2 — #205 Role Contract (Throw-On-Read & Fail-Closed Boundary)

### Throw-On-Read Contract:
`App\Casts\UserRoleCast::get()` explicitly throws `ValueError` when an unrecognized string is read from `users.role`:
```php
throw new ValueError("{$stringValue} is not a valid backing value for enum App\\Enums\\UserRole");
```

### Fail-Closed Operational Boundary:
The `User` model methods (`canAccessPanel()`, `isAdmin()`, `isAuditor()`, `isWarehouseStaff()`, `isBranchManager()`, `hasAccessToWarehouse()`) catch `ValueError` inside a `try/catch` boundary and safely evaluate to `false`. This prevents database corruption from causing 500 server crashes while enforcing strict zero-access security.

### Panel Authorization Test Evidence (`canAccessPanel`):
- Active user (`is_active = true`) with raw invalid role `'unregistered_role'`: **DENIED** (`canAccessPanel() === false`).
